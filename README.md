# Excel to PDF Web App (Streamlit)

เว็บแอปพลิเคชันสำหรับแปลงไฟล์รายงานสรุปยอด Excel (.xlsx) เป็น PDF อัตโนมัติ

## ฟังก์ชันการทำงาน
1. **ชีท "ยอดค้างรับลูกค้า":** ตรวจหาจุดสิ้นสุดที่แถว `ยอดรวมวางบิลทั้งหมด` อัตโนมัติ ตัดแถวว่าง/เทมเพลต 0 ทิ้ง กำหนดพิมพ์เฉพาะคอลัมน์ A–H และบีบขนาดพอดีหน้า A4 แนวตั้ง
2. **ชีท "ยอดค้างจ่ายหัวลาก":** ตรวจหาจุดสิ้นสุดที่แถวสรุปหลัง `Update` อัตโนมัติ ตัดแถวว่างทิ้ง กำหนดพิมพ์เฉพาะคอลัมน์ A–F พอดีหน้า A4 แนวตั้ง
3. **ตัวเลือกดาวน์โหลด:**
   - ดาวน์โหลดแยกชีท: "ยอดค้างรับลูกค้า.pdf"
   - ดาวน์โหลดแยกชีท: "ยอดค้างจ่ายหัวลาก.pdf"
   - ดาวน์โหลดรวมไฟล์: "รายงานสรุปยอดค้างรับ-ค้างจ่าย.pdf"

---

## วิธีนำขึ้นระบบออนไลน์ (Deploy บน Streamlit Community Cloud - ฟรี 100%)

1. **นำโฟลเดอร์นี้ขึ้น GitHub:**
   - สร้าง Repository ใหม่บน GitHub (เช่น `excel-to-pdf-app`)
   - นำไฟล์ทั้ง 3 ไฟล์ขึ้นไป:
     - `app.py`
     - `requirements.txt`
     - `packages.txt` (สำคัญมาก: ช่วยให้ Cloud ติดตั้ง LibreOffice และฟอนต์ภาษาไทยอัตโนมัติ)

2. **เปิดใช้งานบน Streamlit Cloud:**
   - ไปที่ [share.streamlit.io](https://share.streamlit.io) และลงชื่อเข้าใช้ด้วย GitHub
   - กดปุ่ม **"Create app"**
   - เลือก Repository และ Branch ที่เพิ่งสร้าง
   - ในช่อง **Main file path** ใส่: `app.py`
   - กดปุ่ม **"Deploy"**
   - ระบบจะเริ่มติดตั้งและเปิดหน้าเว็บให้ทันที (ใช้เวลาประมาณ 1–2 นาที)

3. **ส่งมอบให้ผู้ใช้งาน:**
   - คัดลอก URL ของเว็บ (เช่น `https://xxxx.streamlit.app`)
   - ส่งให้ผู้ใช้งาน Bookmark หรือปักหมุดไว้ที่หน้า Desktop / Browser
   - เมื่อต้องการใช้งาน แค่เปิดเว็บ ลากไฟล์ `.xlsx` วาง แล้วกดปุ่มดาวน์โหลด PDF
